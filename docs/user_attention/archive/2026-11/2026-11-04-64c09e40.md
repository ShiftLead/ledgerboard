- **Context:** TD-045's design, `docs/plans/TD-045-host-log.md`, gives event gates a fourth check type, `host-log <kind> [times <N>] "<text>"`. It turns a wait the host itself witnesses (a precheck failing again, say) into a gate, where today it is a retired `Waits` line or an `until` date guess.
  - **The count goes before the text,** so the shared rule that nothing follows the quoted text stands. The sketch had it after.
  - **`since` is the day after the gate's last `gate added` Log line.** The event that prompted the gate never passes it. The cost: a second event later that same day is not counted either. To make the line exist, `set` (and `edit`, on a changed check) now writes `gate added`, which only `new` did.
  - **Host rule, deny by default:** a host counts only records tied to the ledger's own repo, of kinds its configuration declares no more private than that repo, since a lift PR is as public as the ledger. A host with no log gives no outcome, so such a gate waits silently. TD-046 is therefore now also blocked by shiftlead#TD-1295.
