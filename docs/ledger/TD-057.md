## TD-057: The item writers' refusal of a field's name in a text does not say which name matched

**Priority:** Low
**Type:** debt
**Added:** 2026-11-06 (requested by ao-agent-cadence-ac-techlead through ao td add; drafted by ao-ledgerboard-lb-techlead)
**Status:** Open
**Taken by:** ao-ledgerboard-lb-techlead
**Location:** ledgerboard/__init__.py (`_item_words`, `WRITER_FIELD_RE`), fixtures/board_writer/add_refused_field, fixtures/edit, tests/

**Why:** The item writers' refusal of a text that carries a field's name does not say which name matched. `_item_words` (the detail block's lines, an answer, a board line's text, the context) answers with all eight names, "may not carry Context:, Parts:, Due:, Hide until:, Answers:, Lifts:, Decided: or Closed:", so the caller has to find the word by trial. `edit_line`'s refusal of the same fault already names it ("text: names a field (Due:)"). Agent-cadence's techlead reported it on 2026-11-06, from Paul's trial review of three ShiftLead seats' transcripts (2026-11-03 to 2026-11-06): `board_edit` refused a detail or context text carrying `Context:`, `Due:` or `Decided:` three times, and each seat reworded it by trial.

**Fix:** Make `_item_words`' refusal name the field name that matched, quoted as it appears in the text (for example `Due:`), and name the part it was found in, as `edit_line`'s refusal already does. Update the fixtures that pin the old wording (`fixtures/board_writer/add_refused_field`, and any `edit` or `ledger_edit` case that expects it) in the same PR. This changes only the refusal's words, not the format.

The report also suggested a way to write such a word: for example, backticks that the reader then skips. That would change how the reader reads a line, which is a format change (SPEC, a version note), so it is not part of this entry. If it is wanted, it is a design-first entry of its own.

**Done when:** A text refused for carrying a field's name is refused with that name, and the part it was in, in the message. A test or fixture pins this for at least the detail block, an answer and the context. The precheck is green (`ruff check .`, `python3 -m unittest discover -s tests`, `python3 fixtures/run.py`).
