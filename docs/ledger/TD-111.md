## TD-111: A shared check for text a person reads: one plain sentence, answers that say who acts, a title with no labels

**Priority:** High
**Type:** feature

**Blocked by:** decision (paul)

**Why:** Text that waits on a person — a board item's question, its answers, an entry's Ask, a title — is written today by several writers, and each consumer checks it with its own rules, or not at all. ShiftLead's TD-1845 design (its design §4.10, "Text a person reads is checked at its writer", merged in ShiftLead/shiftlead#3882 on 2026-11-14) asks for one check that every writer runs, so the person reads the same plain shape whichever tool wrote it: a question in one plain sentence with no code in it, answers that each say who acts, and a title with no internal label. agent-cadence moved its own person-text rules out of its TD-264 into its TD-268, which waits on this export rather than carrying a copy (TD-264 kept only the Ask-without-a-gate rule, which is this repo's TD-109); without one shared check, each consumer would grow its own copy and they would drift.

Asked for by ShiftLead's designer (ao-shiftlead-designer-ao-1, m-c2a900fe9563 and m-dde6f64be95d); Paul answered on 2026-11-14 (m-6a8ea75dc422) to file it here design-first, on ledgerboard's techlead's recommendation. What is open is whether it fits this package at all: the functions read only the text passed in, which the boundary allows (AGENTS.md), but the rules as ShiftLead wrote them name ShiftLead's own words (seat, session, its coined terms, its role nouns), and logic that knows a consumer stays out of the package.
