## TD-111: A shared check for text a person reads: one plain sentence, answers that say who acts, a title with no labels

**Priority:** High
**Type:** feature
**Added:** 2026-11-14 (ShiftLead's designer, through ao td add; Paul's go to file it here, m-6a8ea75dc422; drafted by ao-ledgerboard-lb-techlead)
**Owner:** designer
**Kind:** design-first
**Status:** Open
**Id take:** 5155df7488194d20a87da40129407e96

**Why:** Text that waits on a person — a board item's question, its answers, an entry's Ask, a title — is written today by several writers, and each consumer checks it with its own rules, or not at all. ShiftLead's TD-1845 design (its design §4.10, "Text a person reads is checked at its writer", merged in ShiftLead/shiftlead#3882 on 2026-11-14) asks for one check that every writer runs, so the person reads the same plain shape whichever tool wrote it: a question in one plain sentence with no code in it, answers that each say who acts, and a title with no internal label. agent-cadence moved its own person-text rules out of its TD-264 into its TD-268, which waits on this export rather than carrying a copy (TD-264 kept only the Ask-without-a-gate rule, which is this repo's TD-109); without one shared check, each consumer would grow its own copy and they would drift.

Asked for by ShiftLead's designer (ao-shiftlead-designer-ao-1, m-c2a900fe9563 and m-dde6f64be95d); Paul answered on 2026-11-14 (m-6a8ea75dc422) to file it here design-first, on ledgerboard's techlead's recommendation. What is open is whether it fits this package at all: the functions read only the text passed in, which the boundary allows (AGENTS.md), but the rules as ShiftLead wrote them name ShiftLead's own words (seat, session, its coined terms, its role nouns), and logic that knows a consumer stays out of the package.

**Location:** SPEC.md (a new section: text a person reads); ledgerboard/__init__.py (new exports); ledgerboard/board.py, ledgerboard/ledger.py (whether add, new and set call it); fixtures/

**Fix:** Design first (lb-designer). The design settles, in order:

1. Whether a prose check belongs in ledgerboard or in agent-cadence. It belongs here only if it can be written over the format's own text with nothing that knows a consumer: whatever is ShiftLead's own vocabulary (ACTOR_NOUNS, COINED_TERMS, its people) is passed in by the caller, as `pickable()` takes its resolver, never a constant in the module. If it cannot, the design says so and this entry closes with a pointer to where it went instead.
2. If it belongs here, the exported functions and their contract: `person_text_problems(sentence, answers=(), context=None, *, question, people=(), default=None)`, `title_problems(title)`, `sentence_problems(text, *, question, max_words)` (rule 1's word count and sentence end alone) and `code_tokens(text)` (the code tokens found, in order, each once), the first two each returning a list of (rule, refuse, line); the constants (`SENTENCE_WORDS` = 25, `CODE_EXTS`, `ACTOR_WORDS`, and which of ShiftLead's are passed in instead). Rules: 1, one plain sentence of at most 25 words with no code token (a question ends in ?); 2, every answer, label and consequence, names who acts; 3, a title has no code token and no internal label (B4, F123, TD-n, #n, a coined term); 4, the context's code tokens are a warning, never a refusal. Rules 1 to 3 refuse. The token patterns, actor regexes, known false positives and line wording are in ShiftLead's design §4.10; the design here adopts or departs from each, saying why.
3. Whether this package's own writers call it (`board.py add`, `ledger.py new` and `set` on an Ask, a title) or only export it, and the SPEC text and fixtures that pin it.
4. The release: a minor (it adds functions and reads nothing it did not), and its consumers' order — agent-cadence vendors it (its TD-268's event gate reads `person_text_problems` in `ledgerboard/__init__.py`), then ShiftLead's TD-1846 bumps its copy. On the release, tell agent-cadence's techlead (ao-agent-cadence-ac-techlead) its number, so that its TD-268 can vendor it and call it.

**Done when:** Either the design records that the check does not belong in this package and where it went instead, or a ledgerboard release exports the functions as the design's SPEC text says, with their fixtures, and agent-cadence's techlead has been told which release carries them.
