## TD-035: Nothing shows that unknown text survives every writer, that an older minor reads a newer one safely, or that SPEC's grammar matches the fixtures

**Priority:** Medium
**Type:** feature
**Added:** 2026-11-03
**Status:** Open
**Taken by:** 2e9dce7d0dea
**Blocked by:** TD-034
**Part of:** TD-010
**Location:** fixtures/ (cross-cutting cases, a release tag per case); fixtures/run.py; tests; SPEC.md Appendix: grammar

**Why:** Principle 7 and the cross-version promise need fixtures of their own, and the grammar appendix is informative only if a test keeps it in step with the fixtures (target design §7.4).

**Fix:** Per target design §7.4:
- *Unknown text survives*: an unknown header field, gate, body section and Log prefix through `edit` and `fmt` with its content unchanged; a header line that is not a field refused;
- *Cross-version*: a v2.4 reader resolving an `other#TD-n` archived as `Dropped D` reads it as closed; a minor reader never reads a block as lifted or a closed entry as open from a newer minor;
- *Grammar*: each EBNF production has a fixture that accepts and one that refuses, and a test checks every fixture against the EBNF;
- *Fixtures carry the release they apply to*, so a consumer runs the set for its own pin;
- any §7.4 v2.4 fixture the earlier builds did not add.

**Done when:** The fixtures and the grammar test are in, each fixture names its release, and the suite passes.
