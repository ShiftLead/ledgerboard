## TD-016: Each consumer writes board files its own way: ledgerboard has no board writer over files

**Priority:** Medium
**Type:** feature
**Added:** 2026-11-02
**Status:** Open
**Taken by:** 2e9dce7d0dea
**Blocked by:** TD-015
**Part of:** TD-008
**Location:** ledgerboard (see Fix); SPEC.md; fixtures

**Why:** agent-cadence's `board_edit.py` and ShiftLead's `board.py` each read, edit and write the board around the module's pure edits, so the file handling drifts between them (target design §1.1).

**Fix:** Target design §1.1: `ledgerboard/board.py`, a git-free command line and importable library. Its commands are the ones agent-cadence's `board_edit.py` wrapper and ShiftLead's `sessionorc/board.py` call (agent-cadence#TD-206, TD-213): `add` (over `item_line`, any kind), `list`, `snooze`, `done`, `decide`, `reply` (over `edit_line`), `archive` (over `archive_closed`), `fmt` (over `canonical_item`, under the key rule), and the rank writes; TD-017 adds `due`. It prints the module's subject and the changed paths (`--json`), takes `--plan` (the changes as JSON, nothing written), writes several files both-or-neither, and takes `--by` and `--today` from its caller. Fixtures: a directory before, a command, the directory after and the subject.

**Done when:** `board.py` covers every board and rank action the consumers use today, with writer fixtures for each, and the suite passes.
