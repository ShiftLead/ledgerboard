## TD-016: Each consumer writes board files its own way: ledgerboard has no board writer over files

**Priority:** Medium
**Type:** feature
**Added:** 2026-11-02
**Status:** Open
**Taken by:** 2e9dce7d0dea
**Blocked by:** TD-015
**Part of:** TD-008
**Location:** ledgerboard (see Fix); SPEC.md; fixtures

**Why:** agent-cadence's `board_edit.py` and ShiftLead's `board.py` each read, edit and write the board around the module's pure edits, so the file handling drifts between them (target design §1.1).

**Fix:** Target design §1.1: `ledgerboard/board.py`, a git-free command line and importable library over `edit_line`, `item_line` and `archive_closed`, plus the rank writes; it prints the module's subject and the changed paths (`--json`), takes `--plan` (the changes as JSON, nothing written), writes several files both-or-neither, and takes `--by`, `--today` from its caller. Fixtures: a directory before, a command, the directory after and the subject.

**Done when:** `board.py` covers every board and rank action the consumers use today, with writer fixtures for each, and the suite passes.
