## TD-003: PRs are checked by GitHub Actions, whose minutes the account's repos share and which have stopped: gate on a local `precheck`

**Priority:** Medium
**Added:** 2026-10-26 (Paul; drafted by session `memory-vs-cadence`)
**Status:** Open. Amended 2026-10-30 (Paul, session `td-191`): this repo is public, so the Fix keeps forge CI on a fork's PR, as agent-cadence decided for itself in TD-192 (Actions on fork PRs only). Released 2026-10-30 (Paul): the fork-only decision is made, so the Fix stands as written. Ready to build.
**Location:** `.github/workflows/ci.yml` (`on: pull_request`, push to `main`, tags `v*`); `docs/cadence.toml` (no `precheck` key); `AGENTS.md`; dev-cadence `cadence.md` §4.12 and TD-148

**Why:** GitHub Actions stopped on the shared account (ShiftLead org from 2026-10-26: *recent account payments have failed or your spending limit needs to be increased*), and Paul decided every repo gates on a local `precheck` instead (dev-cadence TD-148): the minutes are one pool across all the repos, kept for what has to run on GitHub. This repo's `ci.yml` runs `ruff check .`, the unit tests and the fixtures on every pull request and push to `main`, so its PRs now read red for a reason that says nothing about the code. The tag job — a release's module carries its header — is the one that belongs on GitHub.

**Fix:** `precheck = "ruff check . && python3 -m unittest discover -s tests && python3 fixtures/run.py"` in `docs/cadence.toml` (the merge gate runs it with `dev-cadence run precheck.py --pr <n>`, recording `cadence/precheck`); `ci.yml` keeps the tag trigger and `workflow_dispatch`, drops the push to `main`, and keeps `pull_request` for a fork's PR only, with a job `if: github.event.pull_request.head.repo.full_name != github.repository`. A public repo runs Actions free, and a fork's code then runs in GitHub's sandbox, not on the machine through `precheck.py --pr` (agent-cadence#TD-207); `AGENTS.md` names the gate. Done when a PR's gate reads a green `cadence/precheck` and no workflow runs on this repo's own PRs, while a fork's PR runs `ci.yml`.

**Related:** dev-cadence TD-148 (the convention), shiftlead TD-1033, agent-cadence#TD-192 (fork PRs only), agent-cadence#TD-207, shiftlead#TD-1285.
