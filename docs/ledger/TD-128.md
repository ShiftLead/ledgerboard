## TD-128: A board split cuts an item's session at an apostrophe in its host

**Priority:** Low
**Type:** debt
**Added:** 2026-11-16
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 0d8851bb79a345f4a1ca6b16af2768d8

**Why:** `split_board()` cuts a v2 item's session head at the first apostrophe, so the item file's `Session` field loses the rest of the host. A v2 line `- [ ] 2026-09-14 (session b8a7317c on Pat's laptop, main) — …` splits to `**Session:** b8a7317c on Pat's`, and the split warns `head text not carried: laptop, main`. The warning makes it look like ordinary head text (a branch) was dropped, when part of the host itself was cut. Found in the v3 moves of 2026-11-16: seven of contractmatch's archived items now read `on <name>'s` (contractmatch#260's review).

**Location:** ledgerboard/__init__.py (SPLIT_SESSION_RE, split_board)

**Fix:** Read the session head's host up to the head's own separators (`,`, `;`, `)`), not up to an apostrophe (`SPLIT_SESSION_RE`, `SPLIT_HEAD_RE`). Add a fixture for a host with an apostrophe.

**Done when:** A split of a line whose host holds an apostrophe keeps the whole host in `Session`, with a fixture.
