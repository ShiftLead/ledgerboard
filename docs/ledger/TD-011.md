## TD-011: A superseded blocker releases the entries waiting on it before the entry that replaced it lands

**Priority:** Medium
**Added:** 2026-10-31
**Status:** Open 2026-11-02: Shaped in TD-010's round (target design §5: supersede rewires, drop refuses while dependents remain); Paul's go 2026-11-02 lifts his gate; built with v2.4, after TD-008 2026-11-03: Blocked by the v2.3 release (TD-021) rather than TD-008, which archives with TD-019 before the release 2026-11-03: v2.3 is released (TD-021 archived), so its Blocked by goes; it waits for the v2.4 builds the designer files from target design §7.1 (§7.0), since its own Fix is still 'to be shaped' and §5 is marked proposed
**Taken by:** 2e9dce7d0dea
**Waits:** event — the designer files v2.4's builds from target design §5 and §7.1 (v2.3 is released); TD-011's Fix is still open in that round
**Part of:** TD-010
**Location:** ledgerboard.py (pickable, check, edit_entry rename_ref); SPEC.md The archived entry

**Why:** `pickable()` lifts a blocker once its heading is in the archive and never reads how it got there. An entry archived `Superseded … by TD-m` therefore releases every entry blocked by it at once, though its requirement now lives in TD-m, which is still open. cadence.md §2.8 has the superseded entry's remaining asks written into TD-m first, but nothing moves its dependents' `Blocked by` to TD-m. `edit_entry`'s `rename_ref` exists for that and nothing calls it on a supersede. Example: TD-10 is blocked by TD-5; TD-5 is superseded by TD-12; TD-10 is picked and built on a design that lives, unfinished, in TD-12.

**Ask:** Should a supersede rewire its dependents' Blocked by to the new entry, or should the check refuse the archive until they are rewired? Settled with TD-010's round.

**Fix:** to be shaped in its parent's design round. Candidates: `check()` flags an open entry blocked by a superseded one (an error on an edit, so the archive that supersedes must rewire), and `ledger.py archive --superseded-by TD-m` runs `rename_ref` on every open entry that names it, in the same change.
