## TD-008: A new board item and an archive of closed ones are typed by hand: the board's writers cover every write, as the ledger's now do

**Priority:** Medium
**Type:** feature
**Added:** 2026-10-30 (Paul, session `led-tds`: "board.py with alias, item line only, fmt pass, wait")
**Status:** Open 2026-10-30: shape agreed in conversation; design rounds not run
**Taken by:** 965518f644df
**Blocked by:** agent-cadence#TD-202, decision (Paul) — the design's review rounds, then Paul's go
**Location:** `ledgerboard.py` (`item_line`, a new `item_problem` and canonical item writer, a new `archive_closed`); SPEC.md *The board* and *Edits*; `fixtures/board/`, `fixtures/edit/`

**Why:** every board write but the person's four edits is typed by hand. A session adds an item, with its kind, `Answers:`, `(default)` mark and detail block, by writing the line itself, and archives closed items by cutting and pasting them; only snooze, done, decide and reply go through `edit_line()` (agent-cadence's `board_edit.py`). Each hand-typed convention is one an agent can slip on, the way the ledger's did before TD-005. The ledger's fix was one writer and a gate that refuses what the writer would not have written; the board needs the same, and its format half belongs here, since both consumers vendor this module.

**Ask:** once agent-cadence's ledger builds (its TD-197 to TD-202) have landed, run this design's review rounds and give the go?

**Fix:** the shape Paul agreed on 2026-10-30, a minor release (v2.3):
- `item_line()` gains `kind`, `answers` and `default`, so a new `decide` item is written whole; the detail block is composed from named parts (Context, Question, Caveats, Recommended) and never edited by a writer afterwards.
- `item_problem(line)`: why an open item line is not one the writers write, or None; and a canonical item writer that rewrites a line to that form or refuses one it would have to lose text from, for agent-cadence's one-time `fmt` pass over every board.
- `archive_closed(board, archive)`: the closed items moved as whole entries, detail blocks with them.
- The gate checks the item line only; the detail block stays the person's prose.

**Done when:** v2.3 is released with these, SPEC and fixtures together, and agent-cadence's `board.py` can vendor it.

**Related:** agent-cadence's `board.py` entry (its CLI, the alias `board_edit.py`, `fmt` and the gate), to be filed there; TD-005 (the ledger's writers, the pattern); agent-cadence TD-173 and TD-197 to TD-202 (the ledger's CLI and gate, which this waits on).
