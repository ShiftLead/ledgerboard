## TD-023: item_problem() cannot note a stale or over-late Hide until: it has no today and no note channel

**Priority:** Low
**Type:** feature
**Added:** 2026-11-03
**Kind:** design-first
**Status:** Open
**Taken by:** ao-ledgerboard-lb-grinder
**Location:** ledgerboard/__init__.py (item_problem); SPEC.md

**Why:** Target design §6 *Hide until* asks that `item_problem()` note (ℹ) a `Hide until` in the past and one later than the item's `Due:`. TD-017's build (PR for TD-017) leaves both out: `item_problem(line)` takes no `today`, and it has no channel for a note. Everything it returns is a fault, which `board_problems()` (the merge gate) refuses, while §6 asks for an ℹ that informs.

**Fix:** Choose the shape: `item_problem(line, today=None)` with a separate notes list, or a new `item_notes(line, today)` that the gate reports without refusing. Then build it with SPEC text and fixtures: a hide in the past, and a hide later than Due. `snooze` already replaces an existing hide, so a stale date does not linger.

**Done when:** Both notes are reported for a line that carries them and never refuse a write, with fixtures, and the suite passes.
