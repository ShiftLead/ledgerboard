## TD-006: A defect cannot name the design that let it through: `Escaped from` joins the spec's fields, in v2.2

**Priority:** Medium
**Type:** feature
**Added:** 2026-10-30 (Paul, session `td204-design`: "Ride v2.2"; agent-cadence TD-204's design, decided 2026-10-30)
**Status:** Open 2026-10-30: built on main (the field, SPEC, the `escaped` fixture); done when v2.2 is released with TD-005 (and TD-004).
**Taken by:** 2d1e517b5515
**Location:** `ledgerboard.py` `CADENCE_FIELDS`; SPEC.md (the list of the spec's fields); the fixtures for `check()`'s `undeclared-field`

**Why:** agent-cadence TD-204 (ADR `docs/plans/2026-10-30-review-outcomes.md` there) adds a ledger field, `**Escaped from:** <design TD>`, on a defect a design review should have caught. It is the link that lets a design's review record be checked against the defects it later let through. Its value is free (`TD-NNN` or `<repo>#TD-NNN`), so a ledger cannot declare it on a `Fields:` line, which takes only enumerated vocabularies (`declared()`). As an undeclared field it is flagged `undeclared-field` in any ledger that has a `Fields:` line (ShiftLead's), and that is an error under `check --since`, so the PR that adds the field to a live defect fails its gate. `Id take` (agent-cadence TD-188) is in v2.2 for the same reason.

**Fix:** add `escaped from` to `CADENCE_FIELDS` as a free-valued field, and to SPEC.md's list of the spec's fields with one line on its meaning (the design entry a defect escaped from; resolving it is the consumer's, ledgerboard only parses it). It takes no place in TD-005's canonical order beyond "any other field in the order the file had it", unless TD-005's build chooses to list it. A fixture: an entry carrying `Escaped from:` in a ledger with a `Fields:` line raises no `undeclared-field`. Ship in v2.2 (a minor release).

**Done when** v2.2 is released with `escaped from` among the spec's fields and its fixture passes.

**Related:** TD-005 (v2.2); agent-cadence TD-204 (its build vendors v2.2 and waits on this), agent-cadence TD-188 (`Id take`).
