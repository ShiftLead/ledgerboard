## TD-032: The merge gate can't tell a lift PR from a hand edit, so a decide lift can't skip review and a forged lift isn't caught

**Priority:** Medium
**Type:** feature
**Added:** 2026-11-03
**Status:** Open
**Taken by:** 2e9dce7d0dea
**Blocked by:** TD-031
**Part of:** TD-010
**Location:** ledgerboard/__init__.py (lift_pr_verdict, tripwire, uncovered_decisions); SPEC.md; fixtures/verdict

**Why:** agent-cadence's carve-out accepts a tool-made board PR alone. A decide lift writes the board and the ledger, so the gate needs a pure verdict that recomputes the lift, and a tripwire for a `decision` removed with no answer (target design §1.2, §3.1, §6 (a0)–(d)).

**Fix:** Per target design §1.2 (*The lift-PR verdict*, *The merge gate's coverage check*), §3.1 (the tripwire) and §6:
- `lift_pr_verdict(base_tree, head_tree, files, subject, commits, created_at, merged_at, repo) -> {carve_out, flags, review}`: conditions (a0)–(d), `decide_lift`'s byte-equality, the date windows (the UTC Log date and the local `Decided:` date, a day's slack);
- `tripwire(base_tree, head_tree, subject, repo) -> flags`, reading this repo's own board and archive at base and head, with its exemptions (reassign, override, archive, the `ledger: migrate v<release> (<n> entries)` subject, which joins the subject vocabulary) and the `set by=` route's three suffixes;
- `uncovered_decisions(base_tree, head_tree, boards, repo) -> (refusals, flags)`, refusing only on this repo's own board.

**Done when:** The three functions are built with SPEC text and fixtures (base and head trees with each outcome, including a tripwire that reads the head alone failing), and the suite passes.
