## TD-130: Decide whether a board split should attach a paragraph set below an item to that item

**Priority:** Low
**Type:** debt
**Added:** 2026-11-17
**Owner:** designer
**Kind:** design-first
**Status:** Resolved 2026-11-17
**Id take:** 4adc51ff9df54eb98971f6fcb8327f9b

**Why:** TD-129 built the warning: a v2 board split names each line it carries into `README.md` from below an item. It left one question open on purpose. A session sometimes set an indented paragraph after a blank line below an item, such as `**Update <date>:** … Due: <date>.`. The v2 reader never read that paragraph as the item's, so the split now puts it in the README and warns about it. Attaching it to the item's detail block would keep the update with its item, but it changes what the item says, and a `Due` or `Context` inside it would read differently. That makes it a design call, and the person should see it.

**Ask:** Should a board split keep putting a paragraph written below an item into the board's README with a warning, rather than attaching it?

Go: a session archives this entry, nothing is built, and the session running each split moves an item's update by hand. One more round: a session runs another review round, then asks again. Hold with a note: a session revises the design as the note says, such as attaching a shape you name.

**Design PR:** #394

**Location:** ledgerboard/__init__.py (_split_text, _split_items); SPEC.md Migration

**Fix:** Designed: [docs/plans/TD-130-split-trailing-paragraph.md](../../plans/TD-130-split-trailing-paragraph.md) (rounds: [docs/reviews/TD-130.md](../../reviews/TD-130.md); in plain words: [docs/synopses/TD-130.md](../../synopses/TD-130.md)). The split does not attach a paragraph set below an item after a blank line: the v2 detail block ends at a blank line, the split writes what the v2 reader read, an item file's body cannot hold the paragraph as written, and telling an update from a note would be a guess (D1). TD-129's carry to `README.md` and its warning stand; the session running a split moves an item's update by hand. No build; on Paul's go this entry archives as decided.
