## TD-068: No writer retitles an open entry, and edit writes a section named as a header field

**Priority:** Medium
**Type:** debt
**Added:** 2026-11-11
**Owner:** designer
**Kind:** design-first
**Status:** Resolved 2026-11-11
**Id take:** 6df1c3e5e8ec42b2bb7ea773b5aa9166

**Why:** No writer changes an open entry's title, and `edit` and `set` write a section or a field under any name, `Title` and a header field's included. The title lives only in the `## TD-n: title` heading (`SPEC.md` *The ledger as a directory (v2)*, *Ledger entries and their edits*), and the edits (`ENTRY_ACTIONS`: `set`, `note`, `edit`, …) each keep "the same id, title, fields and sections but for the change", so none can retitle. `edit` (`section`, `words`) adds a section the body lacks and, beside an empty or multi-line name or empty words, refuses only a name two sections share and the Log; `set` (`fields`) sets or adds any field. So `ledger.py edit TD-n --section Title --from FILE` writes a body paragraph `**Title:** <words>` and leaves the heading as it was, and `--section Status` writes a body `**Status:** …` beside the header's `**Status:**` field and `set TD-n --field Title=…` writes a header field `**Title:** …` under the unchanged heading (all three reproduced on 2026-11-11 against `main`). None is refused, and `--check` reports none.

The harm: when a split or a redesign changes an entry's scope, its title can only be fixed by hand, which the cadence forbids (a session writes the ledger only through the helpers), or by deleting the file and filing it again with `ledger.py new --id` under the same id, which drops its Log and history. A mistyped section name leaves a stray paragraph that reads like a field and is not one.

Found by ShiftLead's session `ao-shiftlead-td-1551` (mail m-187a27755a0f, about ShiftLead TD-1551, 2026-11-11): splitting ShiftLead's TD-1664 changed its scope; `edit --section Title` wrote a body `**Title:**` field under the old heading, and the session deleted the file and filed it again under the same id. It asked for a `set --title` (or an edit of the heading), and for `edit` to refuse a section name that is a header field or unknown to SPEC, with tests.
