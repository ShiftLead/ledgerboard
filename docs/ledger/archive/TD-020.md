## TD-020: `split()` keeps a v1 preamble that describes the old layout, and flattens what sat under its `## Summary`

**Priority:** Low
**Type:** debt
**Added:** 2026-11-03
**Status:** Resolved 2026-11-04

**Why:** `split()` carries a v1 ledger's preamble into `docs/ledger/README.md` unchanged, so a split repo's README still says "the summary table below lists exactly the entries…" and links the old archive file, neither of which exists in a v2 directory. The caller warns only about the archive link. Under a `## Summary` heading `split()` keeps only non-blank, non-table lines, so a commented-out entry template there loses its blank lines, and the `---` pair that framed the table is left as two separators with nothing between them. Each fault is cosmetic, but every repo that splits pays the same hand edit, and a missed one leaves a preamble that misdirects the next session (agent-cadence#TD-183, which waits on this release).

**Location:** ledgerboard: `split()` and `_v2_readme()`; fixtures

**Resolved:** 2026-11-04 (PR #132)

**Done when:** Splitting an unedited v1 ledger gives a README whose template is intact and whose v1 wording is reported, and an edited preamble that still names the v1 layout is reported; released, so agent-cadence#TD-183 can vendor it.
